# Règles de collaboration — RadarPulse

## 1. Pas de code sans autorisation explicite

**Ne jamais écrire, modifier ou créer du code sans que l'utilisateur ait dit : `go code`**

- Si une tâche implique du code, analyser d'abord et attendre le mot-clé.
- Si `go code` n'est pas dit, répondre uniquement par une analyse, un plan ou des questions.

## 2. Toujours analyser avant de coder

**Avant tout développement, effectuer une analyse complète :**

1. Lire et comprendre les fichiers concernés
2. Identifier l'impact des changements sur le reste du projet
3. Proposer une approche claire et concise
4. Attendre la validation et le mot-clé `go code`
